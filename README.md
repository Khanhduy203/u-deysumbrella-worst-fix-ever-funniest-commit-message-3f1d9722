An entry for the [Worst Fix Ever: Funniest Commit Message](https://make.fun/bounty/u-deysumbrella-worst-fix-ever-funniest-commit-message-3f1d9722) bounty on [make.fun](https://make.fun/?ref=5fadr1xa).

The program writes a single commit message for a bug fix that made everything worse — the logout crash is gone, because nobody can log out anymore:

> fixed the crash on logout by removing the logout button

## Run it

```sh
node main.ts
```

This writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
